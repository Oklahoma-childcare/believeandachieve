# Believe & Achieve Learning Center LLC — Coalgate, Oklahoma

New responsive five-page static website (Home, Programs, Our Center, FAQ, Contact).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The `dist/` directory contains a complete static copy for Vercel. The build uses Node to copy static pages; no runtime server is required.

## Deployment

- Framework: Other / static (not required to select Vite)
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: folder containing this `package.json`
